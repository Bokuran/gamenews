Необходимо создать два файла изображений:

1. cover.jpg - обложка игры для карточек (рекомендуемый размер: 600x800px)
2. banner.jpg - баннер для страницы игры (рекомендуемый размер: 1920x600px)

Требования к изображениям:

1. Найти официальные изображения игры The Séance of Blake Manor
2. Убедиться, что изображения из официального пресс-кита разработчиков
3. Соответствие жанру хоррора и викторианской стилистике
4. Высокое качество без водяных знаков
5. Соответствие рекомендациям по размерам

Источники для поиска:
- Официальный сайт игры (если есть)
- Страница игры в магазине Xbox/Microsoft
- Официальные аккаунты разработчиков в социальных сетях
- Игровые издания с оригинальными скриншотами
